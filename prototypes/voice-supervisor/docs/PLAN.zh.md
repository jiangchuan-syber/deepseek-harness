# 语音主调度基础版本改造计划

本原型验证三角色流程，不替换正式桌面安装，不连接开发板。开发分支为 `codex/voice-supervisor-prototype`，基线为上游 `dsh-v0.2.2-alpha.2`。完整需求见 [PRD](PRD.zh.md)。

## 范围与实现顺序

1. 以可选 Cordis 插件接入主会话输入和事件：提交立即确认，不等待整个 Agent 空闲，不用 busy 拒收用户后续话语。
2. 保留 Harness 原生子任务及工具权限体系。使用独立的临时 Harness home、工作目录和会话验证主会话在子任务运行时是否真正能生成回答。
3. 前台通过 DeepSeek API 使用 Flash 模型关闭思考，输出一句简短接话；模型名可配置。本实验不声称 Flash 的参数规模已知或它是可获得的最小模型。
4. 虚拟 ASR 提交预设用户文本。虚拟 TTS 生成带字符边界的确定性时间轴，虚拟播放器按时钟前进并回传游标；它们的延迟是模拟参数，必须与真实模型延迟分列。
5. 唯一输出仲裁器保证先接话再正式回答，前台正在播放时不被普通结果硬切；用户打断立即使旧周期失效。
6. 保存生成文本、实际模拟播放前缀和未播后缀。下一轮将送达记录作为明确的应用事实与用户新话语一同提交主会话，保留 Harness 原始历史，不编辑会话文件。
7. 做离线自动测试、真实 Harness 组合测试和至少一次真实 DeepSeek API 场景，保存指标与可复查轨迹，之后提交推送。

## 原型边界

- 不修改核心 agent-loop，不实现新的任务执行引擎，不替代 Harness 原生子任务能力。
- 输出事件按主会话和原生事件序号关联。消息 accepted 不等于这条消息独占之后整个会话输出；不使用 whenIdle 作为逐消息完成凭据。
- 设备位置是虚拟播放器的精确字符时间轴。真实 ESP32 的采样游标、I2S 延迟和 TTS 词对齐仍需后续固件接入，不把虚拟结果当作硬件验证。
- 只用合成测试文本和临时测试目录；密钥从进程环境或现有本机凭据读取，不复制到仓库或报告。
- 模型接口失败直接记录失败，不以录制或 mock 模型响应冒充真实模型测量。

## 验收矩阵

| 要求 | 证据 |
|---|---|
| 正常先接话后正式回答 | 播放轨迹中 intro.completed 先于 answer.started |
| 正式回答提前就绪不硬切接话 | 两者重叠生成，播放顺序断言通过 |
| 用户打断 | 有中途游标，旧周期待播音频不再播放 |
| 已播上下文回传 | 下一次真实调度请求包含已播前缀和未播后缀；调度回复承认边界 |
| 主子任务并发 | 原生子任务 start 到 end 期间接受新用户话语，并在 end 前产生主会话回答 |
| 小模型反馈速度 | 记录请求开始、首字、完成；模型名和 thinking=disabled 可追查 |
| 任务完成 | 原生子任务结束事件和主调度器最终汇报，以及临时目录实际产物/检查结果 |
| 重复和迟到事件 | 离线测试验证游标不倒退、旧周期拒收、清理后无残留监听或进程 |

## 指标

记录 front_first_token_ms、front_complete_ms、prompt_accept_ms、scheduler_first_answer_ms、native_child_duration_ms、handoff_gap_ms、virtual_interrupt_ms、playback_context_delivery_ms。ASR/TTS 延迟和模拟播放速率另列；一次成功运行只是功能证据，不是 p95 基准。

## 运行与回退

插件只在原型 overlay 中挂载。结束测试时先关闭事件订阅与测试 HTTP 服务，再停止隔离 Harness，等待子进程退出。临时 home 和日志保留在忽略目录供复查；不清理或改动用户正式 home。

## 实验记录

执行命令、实际结果、失败修复和最终指标在验证报告中填写。尚未执行的步骤不标为通过。

## 当前工程基线：PRD v0.5

本阶段使用同一原生主会话的 off/high 两阶段，不再为交互运行器额外调用独立接话 API。阶段调度、工具限制、两类子结果回传、真实思考状态、未确认消息上下文和整条消息播放确认分别实现与验证。输入在已有深度请求期间排队，不宣称推理抢占。阶段与待播日志保留在隔离运行目录；不自动重放未知是否已执行的请求。

验证先运行阶段队列的可控并发测试和 Python 音频回执测试，再使用真实 DeepSeek 与原生 subagent 校验样例产物，最后在保留原主会话数据的前提下切换本地服务。真实设备与虚拟音频的结果分别记录；没有设备播放确认时不声称物理播报验收通过。
